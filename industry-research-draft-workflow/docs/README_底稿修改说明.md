# 底稿修改与生成工作流

本目录保存研究底稿 Excel 的最新规范、脚本与最佳案例。当前推荐案例为：

- 范例主题：ARR 数据收集
- 最终底稿：`01_当前底稿/ARR数据收集.xlsx`
- 证据截图：`03_来源截图整理/ARR数据收集_来源截图/`
- 生成脚本：`02_生成脚本/`

## 当前最佳范例

`ARR数据收集.xlsx` 是新版底稿创作范例，适用于“数据/材料收集写成底稿”的场景。它展示了一个完整闭环：资料收集、结构化整理、来源截图、视觉校验、最终中文交付。

范例说明见：

- `范例说明_ARR数据收集.md`

## 通用流程

1. 明确底稿目的和审阅对象。
2. 收集材料、数据和来源链接。
3. 生成可审阅的 Excel 底稿。
4. 将关键来源转换为真实截图。
5. 做截图视觉校验，确认截图能支撑对应内容。
6. 输出中文命名、中文表达的最终交付文件。

详细规范见：

- `底稿创作规范与流程.md`

## 文件命名原则

最终交付文件应使用中文业务名，例如：

- `ARR数据收集.xlsx`
- `AI应用收入数据收集.xlsx`
- `公司财务预测更新底稿.xlsx`

中间脚本和临时产物可以使用英文文件名，便于运行和排错。
