# Architecture Contract

The scaffold generated by `site-rankings-factory` follows the same high-level split as the current rankings projects:

## 1. Crawl layer

- fetch the target page or API response
- cache raw fetch output under `tmp/`
- extract raw site rows
- normalize them into a standard flat model schema

## 2. Storage layer

- write normalized JSON cache
- write full CSV and top-N CSV
- append a crawl snapshot to a local `sqlite` database
- rebuild workbook raw/helper sheets

The database is meant for history and auditability, not as a replacement for the workbook.

## 3. Display layer

- rebuild the workbook display page from standardized helper sheets
- keep the page layout reusable across sites
- keep site-specific changes mostly inside extraction and normalization logic

## Generated project contract

Each generated project includes:

- `generate_<slug>_rankings_excel.py`
- `skills/<slug>-data-refresh/`
- `skills/<slug>-chart-refresh/`
- `tests/`
- `output/`
- `tmp/`

The generated main script leaves two explicit TODO seams:

1. `extract_source_rows_from_html()`
2. `normalize_source_rows()`

That is the main customization surface for future sites.
