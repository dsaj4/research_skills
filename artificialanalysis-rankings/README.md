# Artificial Analysis Rankings

This project was generated by `site-rankings-factory`.

It scrapes the main homepage leaderboard datasets from `https://artificialanalysis.ai/`, stores crawl snapshots, exports normalized files, and builds a workbook dashboard with a reusable display layer.

## Generated layout

- `generate_artificialanalysis_rankings_excel.py`: main entry point
- `skills/`: repo-local refresh skills
- `tests/`: starter tests for workbook structure
- `output/`: workbook, CSV, and sqlite outputs
- `tmp/`: cached source payloads

## Main commands

```powershell
python -m unittest tests.test_artificialanalysis_rankings_excel -v
python generate_artificialanalysis_rankings_excel.py --mode full
python generate_artificialanalysis_rankings_excel.py --mode data-refresh
python generate_artificialanalysis_rankings_excel.py --mode chart-refresh
```

## Current extraction scope

The current implementation reads three homepage JSON-LD datasets:

- `Intelligence`
- `Speed`
- `Price`

Those three datasets are merged by `detailsUrl` into a single normalized model table.

## Output contract

Generated files are written to:

- `output/spreadsheet/artificialanalysis_rankings_models.xlsx`
- `output/spreadsheet/artificialanalysis_rankings_all_models.csv`
- `output/spreadsheet/artificialanalysis_rankings_top20.csv`
- `output/data/artificialanalysis_rankings_snapshots.sqlite`

Temporary fetch and cache files are written to:

- `tmp/api-cache/artificialanalysis_rankings_source.html`
- `tmp/api-cache/artificialanalysis_rankings_normalized_rows.json`
