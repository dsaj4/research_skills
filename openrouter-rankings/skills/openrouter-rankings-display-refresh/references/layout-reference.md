# Display Layout Reference

## Source

The dashboard layout is derived from `example-charts.xlsx`.

## Layout Rules

- Keep a single front-facing `展示页`
- Use a top title and one-line explanatory subtitle
- Use a two-column card layout
- Keep each chart close to `15 x 7.5`
- Place chart summaries directly below each chart
- Preserve Chinese page labels and section headings

## Dashboard Blocks

1. `Top Models Weekly Trend`
2. `Latest Leaderboard`
3. `Kimi Spotlight`
4. `WoW Change`

## Boundaries

- Do not introduce new metrics that are not already available in the current crawl chain
- Do not fetch network data here
- Do not create a second workbook variant
